# Genspark Process Patterns

The MHI 2026 example shows the process to emulate:

1. Start from a known event or niche and ask what public sources can verify.
2. Separate confirmed public facts from app-only/private/attendee-only data.
3. Identify visible speakers, exhibitors, sponsors, companies posting about attendance, and event-adjacent forums.
4. Run parallel searches for people and company LinkedIn pages.
5. Use URL metadata/search snippets as evidence, but label uncertain matches as probable or weak.
6. Expand from one event to adjacent events in the same space using broad and official-source queries.
7. End with a practical prospecting workflow: official app/list first, then LinkedIn/SERP layering, then structured spreadsheet.

Important behavior:
- Never claim a complete attendee list when the event app or LinkedIn area is private.
- Treat search-engine snippets as useful but partial evidence.
- Keep current-year and historical evidence separate.
- Preserve the query strings that found good results so future runs can reuse them.
