## Component Recipe

| # | Component | Section | Notes |
|---|-----------|---------|-------|
| 1 | `sticky-blur-nav` | Global | Transparent → solid on scroll |
| 2 | `scroll-reveal` | All sections | Staggered fade-in |

| 4 | `numbered-feature` | Features | Large serif numbers: "01", "02" etc. |

| 6 | `ghost-outline` | CTAs | Transparent border CTA buttons |

## Page Structure (top to bottom)

1. **Navigation** — `sticky-blur-nav`
2. **Hero** — Navy background + `metallic-shimmer` gold headline
3. **Stats** — `counter-stats` (homes sold, years in business, satisfied clients)
4. **Bento Grid Services** — `bento-grid` (asymmetric card sizes) + `hover-lift`
5. **Numbered Features** — `numbered-feature` (large serif "01", "02") + `monospace-labels`
6. **Environmental Bleed** — `environmental-bleed` (faded property photo as watermark)
7. **Testimonials** — `scroll-reveal` + `gold-gradient-line` accents
8. **CTA** — `ghost-outline` buttons
9. **Footer**

## Reproduction Prompt

> Build an aspirational luxury single-page site for [CLIENT]. Sticky blur nav. Hero with navy/dark background and metallic-shimmer gold gradient animation on the main headline. Counter-stats section showing key numbers (homes sold, years, client satisfaction). Services displayed in a bento-grid layout — asymmetric 2x2 grid with one large feature card and smaller supporting cards, all with hover-lift. Numbered-feature section with large serif numbers ("01", "02") for each service step. Add environmental-bleed — a faded property/product photo at very low opacity as a background watermark. Gold monospace-labels for category text. Thin gold-gradient-line dividers between sections. CTAs are ghost-outline with transparent borders. All sections use staggered scroll-reveal. Palette: real-estate. Mood: aspirational gold luxury, property showcase.

## What Makes This One Special

- **Bento grid layout** — the asymmetric card sizes (one large hero card + smaller supporting cards) create visual hierarchy that no other inspiration uses, making the services section feel curated rather than templated
- **Metallic shimmer on headings** — the animated gold gradient on the hero headline immediately communicates "luxury" and "premium" in a way static gold text cannot, selling the aspirational property lifestyle
- **Environmental bleed + counter-stats combo** — the faded property watermark paired with prominent numbers (homes sold, years) balances aspiration with credibility, which is exactly what real estate buyers need to see
