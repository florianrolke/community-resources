## How to Use Inspirations

1. **Pick an inspiration** that matches your client's industry/mood
2. Read its `.md` file — it lists every component used
3. Claude reads each component's `.md` for the exact code
4. Swap the industry palette to match the client's brand
5. Replace placeholder content with client's actual business info

## Mixing Inspirations

You can combine elements from different inspirations:
- Populon's preloader + Delta Vega's editorial layout
- DriveBy's particle-torus + TeamSIOK's counter-stats
- Dunkertons' Ken Burns hero + EZ Homes' bento grid

The components are designed to be composable.
