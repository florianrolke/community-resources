## Tier Guide

| Tier | What It Means | Dependencies | Performance |
|------|--------------|-------------|-------------|
| **CSS** | Pure CSS — no JavaScript at all | None | Fastest |
| **CSS+JS** | CSS animations + lightweight JS (IntersectionObserver, scroll listener) | None | Fast |
| **JS** | Vanilla JavaScript, no libraries | None | Fast |
| **SVG** | Inline SVG elements (filters, clip-paths, paths) | None | Fast |
| **CSS Grid** | CSS Grid Layout for complex arrangements | None | Fast |
| **Canvas 2D** | HTML5 Canvas with requestAnimationFrame loop | None | Medium |
| **Three.js** | WebGL via Three.js library | Three.js CDN (~150KB) | Heavier |
| **Composition** | Recipe combining multiple components | Varies | Varies |

## How to Use This Catalog

### For Claude (when generating a redesign):
1. Read the client's industry → pick the matching **industry palette**
2. Read the desired style → check **inspirations/** for the component recipe
3. For each component in the recipe, read its `.md` file for the exact code
4. Inject components into the generated HTML in the documented injection points
5. Score with RALPH → if weak on "motion", add more animation components

### For humans (browsing):
1. Click any component name to see the full code + live preview
2. Use the "Pairs well with" section to find complementary components
3. Start with an industry palette, then layer animations and effects on top

### Component Selection by Goal:

| Goal | Recommended Components |
|------|----------------------|
| **Maximum wow factor** | cinematic-full + metallic-shimmer + preloader-curtain + particle-torus |
| **Clean & professional** | scroll-reveal + sticky-blur-nav + hover-lift + gold-gradient-line |
| **Editorial luxury** | parallax-depth-layers + character-reveal + marquee-ticker + geometric-frame + horizontal-scroll-gallery |
| **Tech/modern** | dot-rhombus + gradient-text + glassmorphism + cursor-spotlight |
| **Warm/artisan** | image-hero-kenburns + wave-svg + environmental-bleed + scroll-reveal |
| **Minimal but premium** | scroll-reveal + monospace-labels + ghost-outline + gold-gradient-line + film-grain |
