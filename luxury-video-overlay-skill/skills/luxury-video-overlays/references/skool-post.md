I just packaged a workflow I have been building for long-form YouTube edits: Agent Zero handles the deterministic editing on the server, then a Remotion/Codex skill adds luxury overlay cards, full-screen statement slides, bottom ticker motion, timed sound effects, and held zoom-in emphasis cuts. The goal is to turn a normal talking-head recording into a much more premium edit without manually rebuilding the same graphics logic every time.

The setup is intentionally split into layers. Agent Zero does the heavy lifting first: silence removal, speech padding, jump cuts, audio cleanup, and transcript generation. Then the luxury overlay skill uses that edited base video plus the transcript to decide where cards, bullet reveals, number counters, key-point flashes, scene transitions, and SFX cues should go. Every visual action is paired with audio: whooshes for card movement, paper-style sounds for bullet reveals, soft bings for emphasis, and transition sounds when the video returns to talking head.

I made the repository shareable so the community can install it without exposing private environment files, API keys, raw videos, server IPs, or client assets. The repo includes the Codex skill, reusable Remotion components, an example manifest, install scripts, a public-safe Agent Zero handoff guide, and a secret scan script to run before publishing. The practical outcome is that once Agent Zero is installed on your server and producing an edited base video plus transcript, you can reuse this skill to generate a polished long-form edit style instead of starting from scratch every time.
