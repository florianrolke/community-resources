# Community resources

Free Claude Code and Codex skills, tools and templates by Florian Rolke for AI agency owners and creators.
One folder per resource. Each folder has its own README with setup steps.

**Use one:** copy its folder (or clone this repository), read the folder's README or `SKILL.md`, and put your own keys
in your own `.env`. No resource ships with credentials.
