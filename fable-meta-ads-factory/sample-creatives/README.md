# Sample creatives

Six of the generated ad statics, anonymized. Each was produced by
[`../kie-pipeline/generate_ads.py`](../kie-pipeline/generate_ads.py) with Kie AI's
`seedream/5-pro-text-to-image` at 3:4, ~7 credits apiece. The navy headline bar with white uppercase
text is **generated by the image model itself** (baked in), not overlaid afterward.

Note the "interplay" at work (see
[`../methodology/ad-copy-interplay-doctrine.md`](../methodology/ad-copy-interplay-doctrine.md)): the
image headline opens a loop that the ad's *headline* answers. For example, the utility-doorway image
reads **"NOBODY PAYS PLUMBERS FOR SPOTTING WATER DAMAGE."** — and the ad headline that ran beneath it
answered **"We do. $100 the same day."**
